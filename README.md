# كشكول زهر الآداب وثمر الألباب

كتاب رقمي صغير للقراءة والحفظ، مُعدّ للآيفون خصوصاً، يضع بين يديك شواهد وأبيات **زهر الآداب وثمر الألباب** لأبي إسحاق إبراهيم بن علي الحصري القيرواني (ت 413هـ).

> **الكتاب كاملاً** — 2405 شاهداً موزّعة على 912 صفحة فرعية، مجمّعة في **18 موضوعاً** بدل 453 عنواناً متفرقاً. النص محفوظ حرفياً كما ورد في المصدر، بما في ذلك علامات الترقيم والتشكيل. دُمجت البطاقات التي كانت تحوي كلمة واحدة أو رقماً أو جملة واحدة قصيرة في البطاقة السابقة، مع الإبقاء على المعرّفات متسلسلة. كما أُلحق التعقيب المفسِّر للبيت (مثل «من قول أعرابي…») بالبطاقة نفسها حتى لا تتفرّق فكرة الفائدة الواحدة.

## ما الذي يميّزه؟

- **كشكول لا اختبارات:** لا بطاقات اختبار ولا تقييم ذاتي — فقط قراءة وتظليل وحفظ.
- **النص كما هو:** لا يُعاد صياغة النص ولا تُصحَّح أخطاؤه تلقائياً؛ يمكنك تعديل أي خطأ من داخل التطبيق عبر «تصحيح النص»، ويُحتفظ بالأصل.
- **ملف واحد بلا تبعيات:** `index.html` واحد يحمل كل شيء (التنسيق، السكربت، والبيانات). لا خادم، لا قاعدة بيانات، لا أدوات بناء. تُحمَّل بيانات الكتاب على دفعات في سكربتات صغيرة منفصلة لضمان عملها السلس على متصفحات الآيفون.
- **المظهر الورقي الأصلي** (الخلفية `#fbf7ef`، البطاقات `#fffdf8`، إطار الأبيات `#faf4e8`، العناوين `#8a5a2b`)، وخمسة خطوط عربية، وحجم خط من 14 إلى 44 بكسل، ولون تظليل قابل للتغيير. لا توجد مظاهر بديلة أو زر تبديل مظهر.
- **أدوات القراءة:** تفضيل البطاقات والأبيات، حالة حفظ ثلاثية (للحفظ؟ ← أحفظه ← حفظته ✓)، نسخ مع الإسناد، ملاحظات، تظليل النص مع ملاحظة، إشارة مرجعية، وإحصاءات.
- **أبيات اليوم:** ثلاثة أبيات تتغيّر يومياً من المفضلة أو قيد الحفظ، مع إمكانية إخفاء العجز للاستظهار.
- **بحث غير حساس للتشكيل** في متن الكتاب وملاحظاتك، وتصدير JSON و Markdown.

## الخصائص الشكلية المطبَّقة

من تصميم مرجعي اعتمده الكشكول، نُقل نظام الألوان والمقاسات والعناصر بدقة:

- **الألوان:** خلفية `#fbf7ef`، بطاقات `#fffdf8`، حبر `#2c241b`، كتمان `#6e6154`، لون مميّز `#8a5a2b` مع تدرّجه `#f2e6d5`، حدود `#e6dccb`، إطار الأبيات `#faf4e8` بحدود `#eadec9`، خلفية الملاحظة `#f8f2e7`، خلفية المحرر `#f4efe6`، أخضر للحفظ `#2e6b47`.
- **الترويسة والتبويب:** شريط علوي لاصق بخلفية شفافة وتأثير `backdrop-filter: blur(10px)`، عنوان من سطرين (16px + 11px)، وشريط تبويب سفلي ثابت بتأثير `blur(12px)`.
- **المسافات:** حاوية بعرض أقصى 820px، بطاقات بنصف قطر 16px وحشوة 16px وظل خفيف، فقرات النص مبرّرة، وإطار قصيدة بنصف قطر 12px.
- **الأبيات:** على الشاشات الصغيرة كل شطر سطر كامل (الصدر يميناً والعجز يساراً) مع فاصل خفيف بين الأبيات، ومن 600px فأعلى يصبحان متجاورين بمحاذاة متقابلة.
- **العناصر:** حُبوب الموضوعات دائرية (`border-radius:999px`) تحوي اسم الموضوع وعدد صفحاته، أزرار بحالات `btn-soft` و`btn-ok`، شارات `badge` و`badge-edited`، شريط إحصاءات بصيغة `قيمة/عنوان`، نافذة تظليل باقتباس مؤطّر، وزر تظليل عائم أسفل الشاشة لا يتعارض مع قائمة النسخ في Safari.
- **التصنيف الموضوعي:** عُناوين الأقسام الـ453 صُنّفت بقواعد كلمات مفتاحية إلى 18 موضوعاً (الرسول والصحابة، البلاغة، المديح، الهجاء، الرثاء، الغزل، الوصف، الحكمة، الملوك، الأدباء، الفكاهة، السفر، الكتب، الشراب، الشباب، آداب المجالسة، الفهرس، متفرقات). عند اختيار موضوع تظهر صفحاته فقط، مع إبقاء اسم القسم الأصلي داخل قائمة الصفحات وفي شريط العنوان.

## Opening على iPhone (إضافة إلى الشاشة الرئيسية)

1. أرسل ملف `index.html` إلى iPhone (عبر iCloud Drive أو AirDrop أو رابط GitHub Pages).
2. افتح الملف في **Safari** (ملفات محلية من Files) أو افتح رابط النشر.
3. اضغط زر **المشاركة** (المربع مع السهم للأعلى) في أسفل Safari.
4. اختر **«إضافة إلى الشاشة الرئيسية»** ثم **«إضافة»**.
5. سيظهر الكشكول كأيقونة تعمل بلا شريط Safari، مع مساحة آمنة لأعلى وأسفل الشاشة.

> ملاحظة: على iPhone، فتح ملف محلي مباشرة من Files قد يكون محدوداً في بعض إصدارات iOS؛ أنسب طريقة هي النشر على GitHub Pages ثم فتح الرابط في Safari.

## النسخ الاحتياطي مهم

كل ملاحظاتك وتعديلاتك وتفضيلاتك تُحفظ **في هذا الجهاز فقط** داخل `localStorage` تحت المفتاح `zahr-aladab-v2`. إذا مسحت بيانات Safari أو غيّرت الجهاز ستفقدها. بيانات النسخة التجريبية القديمة (`v1`) لا تنتقل تلقائياً؛ صدّرها ثم أعد استيرادها من الإعدادات.

- من **الإعدادات ← تصدير JSON** نزّل نسخة احتياطية دورياً باسم مؤرّخ.
- من **الإعدادات ← استيراد JSON** استعد نسخة سابقة.
- **تصدير Markdown** يعطيك ملفاً مقروءاً بالتظليلات والأبيات والملاحظات والتعديلات.

## المصدر والتحويل

- المصدر: ملف EPUB لكتاب **زهر الآداب وثمر الألباب** (رقم 488 في المكتبة الشاملة).
- الاستخراج: الكتاب كاملاً (454 قسماً)，مع ضبط كل بيت على الصورة `(الصدر ... العجز)` وتوحيد فواصل الأبيات (نقاط أو شرطة سفلية) دون تغيير أي حرف عربي.
- الحالات الحافة التي تم تسجيلها دون تعديل: 977 سطراً قصيراً بلا فاصل بين الشطرين، و452 بيتاً كانت فواصلها شرطة سفلية فوُحّدت إلى ` ... `. البطاقات التي يستشهد المصدر فيها بشطر واحد فقط (151 بطاقة) تحمل وسم «شطر» في رأسها؛ لا يمكن إكمالها لأن النص يُحفظ حرفياً.

## النشر على GitHub Pages

استبدل `YOUR_USERNAME` باسم مستخدمك. الأوامر تفترض أنك داخل مجلد `zahr-aladab-kashkol`:

```bash
git init
git add index.html README.md
git commit -m "Add zahr al-adab digital kashkol"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/zahr-aladab-kashkol.git
git push -u origin main
```

ثم فعّل Pages من إعدادات المستودع: **Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save**.
أو باستخدام GitHub CLI:

```bash
gh repo create YOUR_USERNAME/zahr-aladab-kashkol --public --source=. --remote=origin --push
gh api repos/YOUR_USERNAME/zahr-aladab-kashkol/pages -X POST \
  -f build_type=workflow 2>/dev/null || true
# أو ببساطة من الواجهة: Settings > Pages > main / root
```

الرابط النهائي: `https://YOUR_USERNAME.github.io/zahr-aladab-kashkol/`

> ملاحظة: يوجد بالفعل مستودع باسم `ZahrAlbab` على الحساب `falmalki` (يحوي ملف README فقط). إن كان متاحاً لك، يمكنك رفع `index.html` إليه وتفعيل Pages من إعداداته بدلاً من إنشاء مستودع جديد.

### رفع يدوي من Safari على iPhone (بدون أوامر)

1. أنشئ مستودعاً جديداً على GitHub باسم `zahr-aladab-kashkol` (من تطبيق GitHub أو متصفح Safari).
2. افتح المستودع ← **Add file ← Upload files**، واختر `index.html` و `README.md` من Files، ثم **Commit changes**.
3. **Settings ← Pages ← Build and deployment**: Source = `Deploy from a branch`، Branch = `main`، Folder = `/(root)`، ثم **Save**.
4. انتظر دقيقة، ثم افتح الرابط أعلاه في Safari وأضفه إلى الشاشة الرئيسية.
